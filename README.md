# fml_pkg_bin

Бинарный пакетный менеджер (`x86_64` / `amd64`) для Linux From Scratch (LFS) с автоматическим разрешением зависимостей. Написан на чистом Python без сторонних библиотек.

## Принцип работы
1. **Синхронизация (`sync`)**: скачивает `repo.json` в `/var/lib/fml_pkg_bin/repo.json`.
2. **Зависимости (`install`)**: рекурсивно проверяет и ставит все пакеты из списка `depends` перед установкой целевого пакета.
3. **Установка и манифесты**: распаковывает `.tar.xz` во временную папку `/tmp`, переносит файлы/симлинки в `/` и сохраняет их список в `/var/lib/fml_pkg_bin/manifests/<имя>.list`.
4. **Обновление и удаление (`update`, `remove`)**: сравнивает версии, удаляет устаревшие файлы при обновлении и зачищает пустые директории при удалении.

## Команды
* `sudo ./scripts/install_self.sh` — установить пакетник в систему
* `sudo fml_pkg_bin sync` — обновить индекс пакетов
* `sudo fml_pkg_bin install <пакет>` — установить пакет и его зависимости
* `sudo fml_pkg_bin update [пакет]` — обновить пакеты
* `sudo fml_pkg_bin remove <пакет>` — удалить пакет

## Добавление нового бинарного пакета (для разработчиков)
1. Создайте рецепт `recipes/<имя>/build.sh` с метаданными `# name:`, `# version:`, `# depends:` (через запятую) и установкой файлов в `"$DESTDIR"`.
2. Соберите `.tar.xz` и обновите `repo.json`:
   `python3 scripts/build_pkg.py <имя>`
3. Запушьте изменения в репозиторий (`git add . && git commit && git push`).
